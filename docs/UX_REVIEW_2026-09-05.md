# Cleo 桌面版用户体验复验（2026-09-05）

分支：`codex/fun-experiment`。

先用 Windows Computer Use 打开 `%LOCALAPPDATA%\Programs\Cleo\Cleo.exe` 安装版，体验普通聊天、开发历史、会话操作、命令面板、模型设置、主题和记忆总览。随后在本分支修复，并用真实 Python 后端及独立数据目录中的桌面包复验。

## 用户判断

初次体验不满意。普通聊天可以回答实际问题，开发历史和记忆入口也有价值，但草稿会串到新对话、重命名无法使用、键盘提示不兑现、设置出现无效控件。这些问题直接影响用户对应用的信任，比继续增加功能更值得优先处理。

修复后，本次体验覆盖的日常流程已达到我愿意继续使用的程度：聊天入口清楚，建议可以先编辑再发送；切换任务和记忆页不会串用草稿；发送受阻有反馈；历史可以重命名并恢复；主题、模型表单和运行状态能表达实际行为。

## 追加：原生窗口按钮主题同步

用户截图指出浅色主题右上角仍有黑色区域。该区域是 Electron 原生窗口按钮，原来的颜色只在创建窗口时固定为深色，React 的 CSS 主题不会改变它。

通过独立于后端的窄 IPC 接口，把界面主题同步给当前窗口的 `setTitleBarOverlay`；背景使用与标题栏一致的颜色，图标同步调整对比度。接口仅接受 `light` / `dark`，在 Windows 和 Linux 上应用，mock 与真实后端均可使用。

新增原生标题栏回归检查，覆盖浅色、深色、再次浅色以及保存主题后的重载；UX 检查增至 11 项。TypeScript/Vite、19 项桌面后端测试、真实后端 smoke 和打包 smoke 通过，打包预览版也进行了 Windows Computer Use 视觉复验。对应已有 [#8](https://github.com/StDoses72/Cleo-AI-agent/issues/8)。
