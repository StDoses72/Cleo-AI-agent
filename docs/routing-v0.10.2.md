# 路由功能与 v0.10.2

本地定制版以官方 `v0.10.2` 为源码基准，保留新版项目选择、草稿权限、模型延迟切换、消息队列重试和思考深度滑块。

- 输入栏的模型菜单同时提供「指定 harness」和「子任务路由」，下方沿用新版模型、思考深度与速度控件。
- 选择另一个主模型后，随下一条消息交接；子任务自动路由仍不改变主会话模型。
- 新建任务时，路由模式和权限分别保存；评估结果不能扩大执行权限。
- 保留账户与 harness 可用性过滤、AA 缓存与排名、可选评估器、安全子任务交接和有界升级。
- 上下文容量按实际模型元数据读取；当前任务用量保留模型、职责、token 和美元列。
- 侧栏预览读取本地配置，禁止通过预览发起模型推理。

迁移验证使用本地 fixture 和 fake provider，不发送真实推理请求，不代表线上模型连接已验证。进化构建通过同一源码的完整检查后才能应用；现有连接、路由策略和会话数据继续保留。
