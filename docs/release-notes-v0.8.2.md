# Cleo v0.8.2

Cleo v0.8.2 is a small follow-up to the v0.8.1 interface refresh that restores two conversation behaviours.

## Highlights

- Expand the thinking process automatically while a turn has no final answer, collapse it once the answer arrives, and keep any manual toggle after that.
- Always show the thinking process above the tool process within a turn, even when the first tool call arrives before the first thought.

## Upgrade notes

- Existing conversations, memory, configuration, and backend architecture are preserved; no migration is required.
