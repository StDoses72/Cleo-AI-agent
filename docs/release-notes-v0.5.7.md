# Cleo v0.5.7

## 修复

- 移除自我迭代验收案例对需求原文的逐字匹配检查。模型可以概括对应要求，空格或措辞差异不再阻断案例生成。
- 修复 Windows 上独立 Codex 运行目录缺少原生沙箱配置，导致普通读取和执行命令被策略拒绝的问题。缺省使用无需管理员初始化的原生沙箱，并保留显式配置的优先级。
- 保留工作区写入边界、共享用户数据兼容要求，以及版本选择器和恢复控制器保护。

## 范围

此版本修复需求准备与命令执行，不包含 computer-use 功能。已有需求和待验收项继续保留。

## 发布准备

Windows 本地安装包应通过完整构建检查与启动检查。正式发布时继续运行仓库已有的跨平台 CI 和依赖一致性校验。
