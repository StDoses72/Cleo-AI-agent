# 持久上下文交接 v1

## 已实现

- `ConversationContext` 集中管理确定性投影、带来源的工作状态引文、预算、不可变快照和证据读取。
- 有可对应最终回答的流式片段不重复进入上下文；未完成输出仍保留。原始事件日志不重写、不截断。
- 快照位于会话目录 `context-v1`。证据正文按内容 hash 共享，快照引用正文对象；不是每轮复制全部工具输出。`latest.json` 是可重建的工作状态指针。
- 每轮结束生成确定性工作状态；检查点失败不把已完成的模型轮次变成失败，下次切换会重建或报告具体错误。当前仍需扫描源历史，尚未实现增量投影性能优化。
- 工作状态是带类型和事件引用的原文摘录，不是 LLM 语义总结；截取和外置有显式标记。
- `cleo_context` 只暴露 `read_context` 与 `search_context`，在启动进程时绑定一个会话与快照，不接受目标会话参数。保留既有 `cleo_memory` 的原权限；新通道不扩大通用记忆的访问范围。
- 快照与正文 hash 校验；读取冻结事件前缀，忽略后来正在追加的半行。原始证据先脱敏再提供给模型。
- Codex/Claude 的创建、重连配置携带快照绑定；Claude 对两个 MCP 连接状态预检。Codex 配置将该 MCP 标为 required，仍需实际模型端验证工具可用性。
- 交接准备、提交、首轮完成分别记录。未确认执行结果的历史在后续交接中附警告，不自动重发旧用户请求。
- 新运行时之间使用跨进程非阻塞会话锁；切换前复查源 revision。提交事件 fsync，事件已提交但清单落后时按已验证提交记录恢复。任意无法解释的损坏不自动覆盖。
- 前端展示准备/提交状态；跨层契约测试检查 renderer 字面请求是否已在 Electron 注册。

## 范围与边界

这是基础实现，不是方案中全部后续优化。未引入额外收费模型摘要、向量库、厂商原生上下文文件迁移、附件副本保存或全量数据库迁移。

默认正文预算 24 KB、交接正文与新消息合计 64 KB、证据页正文 8 KB，均是保守应用字节预算，不是模型容量声明。真实模型 token 预算探测、分段语义摘要与质量评测、垃圾回收/保留期限、增量投影、更多 ACP Adapter 列为后续工作。

只读通道限制的是工具入口，不是整个模型进程的文件沙箱。运行仍使用目标 Harness 原有配置的权限；本次不新增权限也不把旧审批作为新授权。不同 Harness 的沙箱并不等价，不能宣称跨 Harness 保留了完全相同的 OS 隔离。

新运行时的锁无法约束完全不理解协议的旧程序。切换应用版本前应停止当前任务，避免旧/新程序同时写同一数据目录。数据格式保留旧字段和包装，不等于旧程序能正确执行新交接行为。

快照保存了脱敏后的证据，用户删除整个会话目录时一并移除；当前不主动删除历史快照，后续需加入明确保留策略。长历史保存可追溯不等于模型理解绝对无损。

## 自动验证入口

- `python -m unittest discover -s tests/desktop -p test_conversation_context.py -v`
- `python -m unittest discover -s tests/desktop -p test_harness_switch.py -v`
- `npm run test:context --prefix ui`
- 回归范围：`tests/desktop tests/integrations tests/sessions tests/memory`

所有提交仓库的测试内容为合成夹具。真实账号验证使用单独测试会话，不把用户原教材或历史复制进测试。
