# 电脑操作：独立桌面与本机桌面

在右侧「电脑」面板选择操作环境，再输入 `/computeruse 操作需求`，使用当前会话的模型。
没有 on/off 命令。模式保存在主配置旁的 `computer-use.json`，适用于所有会话；任务执行期间不能切换。

- **独立桌面 · Docker**（默认）：在右侧 Linux 桌面运行浏览器和应用，工具开始执行时自动打开预览。
- **本机桌面 · Windows**：通过 Windows-MCP 使用真实鼠标键盘，直接打开或切换本机应用；无需 Docker。
  不强制打开右侧预览，也不限制在 Cleo 窗口中，可以最小化 Cleo 观看实际桌面。
  需要登录时由 agent 等待用户在原应用中输入，随后在聊天中告诉它继续；聊天和电脑面板均可停止任务。

两种模式都沿用当前会话的审批设置。Codex 的无审批请求模式允许这两个内置电脑工具运行；
请求批准或自动审查模式继续交给原生审批流程，不修改会话沙箱、其他工具或自定义 MCP 的权限。
本机模式首次调用会通过随附的 uv 准备 Windows-MCP 0.8.5 与 Python 3.14，缺少缓存时需要联网。

下列预览、接管和 Docker 运行条件适用于独立桌面。
桌面包含 Chromium、文件管理器、文本编辑器和终端，不会切换主机窗口或操作主机鼠标键盘。
Windows 专用软件不属于这个 Linux 环境；主机文件和主机浏览器的登录状态不会自动共享。

## 观看与接管

右侧使用实时 VNC 画面，支持鼠标点击、滚动和键盘输入。可放大面板查看完整桌面。
点击画面或「接管」后，AI 暂停电脑操作，你可直接登录网站或操作应用。
中文等无法直接输入的文字可通过画面下方的输入框发送；内容发送后清空，不进入聊天或工具记录。
「交回控制」会先处理完已发送的键盘事件，再恢复 AI。人工接管期间，模型不能截取桌面画面。
模型工具最多等待接管 10 分钟；若上层模型连接更早结束，交回后在聊天中继续任务即可。

暂停观看、关闭面板或隐藏 Cleo 窗口只断开画面连接，不取消任务，也不会自动交回人工控制。
「停止任务」取消当前任务；没有任务运行时可用「关闭桌面」释放运行资源。
独立桌面中的浏览器资料保存在专用 Docker 数据卷，关闭桌面、重启 Cleo 或更新程序不会删除它。
网站仍可自行使登录过期；该环境不会导入主机已有的账号资料。

## 运行条件

需要安装并启动 Docker Desktop（Windows 使用 Linux containers / WSL2），或兼容的本地 Linux Docker。
首次使用从随程序分发的 Dockerfile 构建桌面镜像，需要网络并会下载浏览器等依赖；后续直接启动。
默认上限为 4 GB 内存、4 个 CPU 和 512 个进程；没有固定后台启动任务。
每个 Cleo 数据目录使用一个共享桌面，多个任务应顺序使用，避免不同任务交叉操作同一应用。

服务端口仅映射到 `127.0.0.1`，连接需要随机凭据，不挂载主机目录、设备或 Docker socket。
观看连接在 VNC 服务端设为只读；人工连接只在接管期间开放。
截图仅由模型实际调用 Snapshot 时发送。桌面默认不录像。

需要具有图像理解能力的模型按截图坐标操作；不会假装向不支持图像的模型提供完整界面树。
Claude 的消息缓冲上限为 32 MiB，避免常规桌面截图触发默认 1 MiB 的接收限制。

## 旧配置

`computer-use.json` 仍位于主配置旁，旧字段和未知字段不会被升级重写。
默认 `runtime` 为 `isolated`；界面选择本机时保存为 `host`，保留未知字段。
已有非空 `command` 继续使用自定义 MCP，面板显示自定义状态并保留配置，不覆盖其启动参数。
两种环境故障时都不会自动改用另一种桌面；Docker 未安装时仍可从面板切换到本机模式。

## 验证

`tests/integrations/test_isolated_desktop.py` 覆盖默认路由、回环地址限制、接管等待和取消。
设置 `CLEO_SMOKE_OUTPUT` 为专用测试目录后运行
`python tests/integrations/isolated_desktop_smoke.py`，再在 `ui` 下运行
`node tests/computer-preview.smoke.mjs`，验证真实桌面、VNC 点击、键盘、中英文输入、接管与恢复。
测试使用专用数据卷和测试网页，不登录真实账号；输出目录中的 connection.json 含临时连接凭据，不应公开发布。
