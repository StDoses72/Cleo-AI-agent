# Cleo v0.5.8

- 添加 Windows-MCP 电脑操作：可按需自动调用，也可用 `/computer` 主动触发；使用当前会话的模型。
- 保留截图的图像内容和连续操作的界面状态；独立配置默认关闭，可用 `/computer on` 开启。
- 修复进化需求分析对 JSON 代码块及解释文字的解析，避免有效分析结果因包装格式而失败。
- 修复终端会话选择测试在界面尚未完成布局时点击失效、随后无限等待的问题，避免进化构建卡住。
- 修复 Claude 进化任务的审批模式：此前 acceptEdits 仍会请求命令审批，但进化任务没有人工审批接收端，
  导致 Cleo 自动取消执行。现在只在受管理的进化会话使用 Claude 的 unattended 模式；普通任务权限不变。
- 保留 Codex 工作区隔离、用户数据兼容要求、构建检查和受保护的版本选择器／恢复控制器。

Windows-MCP 采用独立 Python 环境；不改变 Cleo 的 Python 版本。正式发布继续执行跨平台 CI。
