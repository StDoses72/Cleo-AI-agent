# Direct acceptance after application

[中文](direct-acceptance.md) | [Documentation](README.en.md)

After applying and trying a build, click Acceptance (验收) directly. You do not need to write an observation or send feedback first. Application and acceptance are separate actions; feedback helps when you want further changes.

- Acceptance records identify the applied build, source, case, and confirmation time.
- Unapplied or stale builds and superseded cases cannot be completed directly.
- Empty notes stay empty; an existing manual note is preserved.
- Continue editing or give feedback when needed. Cancel a manual case that is no longer required; cancellation does not mark it as passed.

See [local evolution](cleo-evolution.en.md) and [requirements and acceptance](evolution-acceptance-preparation.en.md).
